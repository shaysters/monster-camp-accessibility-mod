# Changelog

## 1.0.1 - 2026-10-31

### Added
- When the title menu has been read, the mod tells you if a newer version is out. Run the installer to update.

### Changed
- The installer accepts GOG and DRM-free copies of the game. It doesn't find them by itself, so use Browse to pick the game folder. The mod has only been tested with the Steam version, and the installer says so.

## 1.0.0 - 2026-10-30

### Added
- Standalone installer (MonsterCampAccessibilityInstaller.exe). It installs MelonLoader if needed, then the mod, and can update, repair, or uninstall.
- When you host an online match, the online code is read digit by digit. Press C in the lobby to hear it again.
- Campfire spots say who is sitting there and how many seats are free; the love log is announced as the love log.

### Changed
- Speech goes through Prism instead of Tolk and direct NVDA: screen readers, braille displays, or built-in Windows speech when no screen reader is running. The mod now talks without a screen reader too.
- The lobby-opened announcement no longer reads the online code itself (it is announced separately).

### Removed
- Linux support.
